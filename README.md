# CoCreateDB

CoCreate DB is a new CoCreate module, started from the CoCreate Authenticate module's project structure. Its implementation is a starter copy and will be adapted for database responsibilities.

## Package

```sh
npm install @cocreate/db
```

## Repository

[CoCreateJS/db](https://github.com/CoCreateJS/db)

## Development

This repository begins on the `dev` branch. The `main` branch is reserved for a later initial release.
